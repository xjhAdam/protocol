This App is a privacy and security protection tool designed to help users protect applications and personal files from unauthorized access.

II. Features Description

  • App Lock Protection

  • Pattern Lock Protection
  • Vault Feature (Private Vault)

III. Vault Service

This App provides a vault feature to help users securely store and manage personal files.

  • Hide and protect photos
  • Hide and protect videos
  • Hide and protect audio files
  • Hide and protect document files (including but not limited to PDF, TXT, DOC formats)
  • Hide and protect APK installation files
  • Import files into the vault
  • Export files from the vault at any time

Files in the vault are stored locally on the user’s device by default. This App does not upload, share, or transmit any vault files to any third-party servers.

Users are responsible for properly safeguarding their password, pattern, or other authentication credentials used to access the vault.

IV. Permission Usage

  • Photo and video access permission: Used to read, import, and manage photos and videos that the user actively adds to the vault.
  • File access permission: Used to read, import, encrypt, store, manage, and export files that the user actively adds to the vault.
  • Auto-start permission: Used to restore app lock protection after device reboot.
