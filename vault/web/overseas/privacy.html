Private Vault Privacy Policy

Release Date: March 4, 2026
Effective Date: March 4, 2026

Private Vault ("we", "our", or "the Application") values your privacy. This Privacy Policy explains how we collect, use, and protect your information when you use the Application.

1. Information We Collect

Private Vault is a local file vault application. Most data is processed and stored only on your device.

We do not collect or store the content of your personal files, including photos, videos, audio, documents, or other vault data.

  • Vault access credentials (such as password or encrypted authentication data, stored locally only)
  • Intruder capture photos (if enabled, stored locally only)

2. Permissions Used

Photos and Videos Permission

Used to read, import, manage, and export photos and videos that you choose to add into the vault. All operations are performed locally on your device.

File Access Permission

Used to read, import, encrypt, store, manage, and export files that you choose to add into the vault. All operations are performed locally on your device.

3. Device Identifiers

Our Application and integrated third-party SDKs (including Bugly, Google AdMob, and Firebase) may collect device identifiers such as Android ID.

Android ID may be used for the following purposes:

  • Core application functionality and security
  • Advertising (Google AdMob)
  • Analytics (Firebase Analytics)
  • Crash reporting and debugging
  • Fraud prevention and security monitoring

This information may be processed by third-party service providers according to their own privacy policies.

4. Third-Party Services

1. Bugly Crash Reporting (Tencent)

Used to collect crash logs to improve application stability.

  • Device model
  • System version
  • App version
  • Crash logs

2. Google AdMob

Used for advertising. May collect advertising ID, IP address, and device information.

https://policies.google.com/privacy

3. Firebase Crashlytics

Used for crash analysis and issue resolution.

  • Device information
  • System version
  • Crash stack traces

4. Firebase Analytics

Used to analyze app usage and improve user experience.

https://firebase.google.com/support/privacy

5. Data Sharing

We do not sell or rent user data.

Data may only be shared with third-party SDKs for analytics, advertising, and application stability purposes.

6. Data Storage

  • Vault files are stored locally on the user's device
  • Vault data is encrypted on the device
  • Crash logs may be sent to Bugly or Firebase Crashlytics
  • Advertising data is processed by Google AdMob

7. Vault Feature (Private Vault)

The Application provides a secure vault feature for storing and managing private files locally on the device.

  • Photos
  • Videos
  • Audio files
  • Documents (PDF, TXT, DOC, etc.)
  • APK files

All vault data is stored locally on the user's device and protected using encryption.

Vault content is never uploaded to any server and is not shared with any third party.

Vault access is protected by user-defined passwords or encrypted authentication mechanisms.

The Application does not provide cloud backup, cloud synchronization, or remote recovery services.

If the user uninstalls the application, clears app data, resets the device, or forgets access credentials, vault data may not be recoverable.

8. Children's Privacy

The Application is not intended for children under 13 years of age.

9. User Rights

  • Access data
  • Delete data
  • Restrict data processing

Since most data is stored locally, users can remove data by deleting files, clearing app data, or uninstalling the application.

10. Updates to This Policy

We may update this Privacy Policy from time to time. Updates will be published within the Application.
