I. Service Description

This App is a file vault tool designed to help users securely store and manage personal files.

II. Features

  • Private Vault
  • Photo Vault
  • Video Vault
  • Audio Vault
  • File Vault

III. Vault Services

This App provides vault functionality to help users securely store and manage personal files.

  • Hide and protect photos
  • Hide and protect videos
  • Hide and protect audio files
  • Hide and protect documents (including but not limited to PDF, TXT, DOC formats)
  • Hide and protect APK installation files
  • Import files into the vault
  • Export files from the vault at any time

Files in the vault are stored locally on the user's device by default. This App does not upload, share, or transmit any vault files to third-party servers.

Vault data includes but is not limited to user-imported file content, encrypted credential data (such as password or pattern information, stored only locally), and optional intruder selfie photos (if enabled, stored only on the local device).

Users are responsible for properly safeguarding their vault access password or authentication information.

IV. Permissions Usage

  • Camera permission: used for optional security features (e.g., intruder selfie feature).
  • Photos and videos access permission: used to read, import, and manage photos and videos that users explicitly add to the vault.
  • File access permission: used to read, import, encrypt, store, manage, and export user-selected files added to the vault.
